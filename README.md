# pdf_editor
This repository contains a thesis project for developing a PDF editor application.

The application is built with Python. It uses pikepdf for low-level file processing and PySide6 for the graphical user interface, following the MVVM architecture pattern.

## Running the application

Clone the repository:\
`$ git clone https://github.com/gergo888/pdf_editor.git`

Enter the repository's root directory:\
`$ cd pdf_editor`

Create a virtual environment:\
`$ python3 -m venv venv`

Activate the virtual environment:\
`$ source venv/bin/activate`

Install the requirements:\
`$ pip install -r req.txt`

Enter the source directory:\
`$ cd src`

Start the application:\
`$ python3 -m pdf_editor`
